# 日本語 nihongo-notes

Mi guía personal de estudio de japonés, armada clase a clase a partir del material del curso
(**みんなの日本語 / Minna no Nihongo**).

Es una sola página HTML con gramática, frases, vocabulario buscable e imágenes por lección.
Todo el japonés tiene su **romaji** al lado.

## Cómo verla

Abrí `clase_japones.html` en el navegador. Funciona offline y no necesita instalar nada.
Las imágenes están en las carpetas `clase_japones_img*/`, así que el HTML tiene que quedar
junto a ellas.

## Qué hay

- `clase_japones.html`: la guía
- `clase_japones_img_MMDD/`: las imágenes de cada clase
- Los PDFs originales de cada clase quedan solo en local (no se suben al repo)
- `tools/check_html.py`: chequea que no haya imágenes rotas ni japonés sin romaji
